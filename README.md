# SequoiaX-AutoPlus

**一句话介绍**：每个交易日收盘后，自动从全市场 5000 多只 A 股里，挑出符合 7 种技术形态的股票，把名单发到你邮箱。

不用盯盘，不用自己写筛选代码，也不用买服务器。

---

## 一、它是怎么干活的

每天自动跑四步：

```
第 1 步   下载当天最新行情        →  存进本地数据库
第 2 步   拿 7 套选股规则过一遍   →  挑出符合条件的股票
第 3 步   查这些股票是什么行业的  →  好读
第 4 步   整理成一封邮件          →  发给你
```

举个邮件的例子（**真实格式，只是内容简化了**）：

```
📅 2026-10-10   📊 2 个策略 · 共 7 只

────────────────────────────────

① 均线金叉+放量突破（6 只）

🎯 买点：5日线上穿20日线，且成交量放大到20日均量的1.5倍
🛑 卖点：跌破20日线，或5日线下穿20日线（死叉）

- 电力　　　福能股份、广西能源
- 港口航运　秦港股份、招商南油
- 山东高速（公路铁路）、上海洗霸（环保）
- 同仁堂（中药生产）、大商股份（一般零售）

────────────────────────────────

② 海龟突破新高（1 只）

🎯 买点：突破近20日最高价，成交额超1亿、收阳且真涨
🛑 卖点：跌破10日最低价（海龟经典退出）

- 中信证券（证券）

────────────────────────────────

板块为东财行业分类；买卖点为策略信号参考，不构成投资建议
```

> ⚠️ **先看清楚**：系统只负责「挑股票」，不跟踪你的持仓，也不会提醒你什么时候卖。
> 邮件里的「卖点」是这套策略在书上的经典退出规则，**仅供参考**，仓位要自己管。
>
> ⚠️ 这只是筛选工具，**不构成投资建议**。

### 一个特点：结果是可以复现的

同一批数据，跑一百遍结果都一样，一只不差。

所以如果你发现「今天的名单和昨天一模一样」，**不是程序坏了，是数据没更新**（比如今天不是交易日，或者数据源还没出数据）。
邮件顶部的日期会告诉你数据截止到哪天：

```
📅 2026-10-10（⚠️ 数据截止 2026-10-09）
```

看到这个 `⚠️` 就说明：本次选股用的是 10 月 9 日的数据。

## 二、能挑出哪些股票

一共 7 套规则，官名叫「策略」。每套规则只干一件事：按它的条件把全市场筛一遍。

| 策略名 | 它在找什么样的股票 |
|---|---|
| **海龟突破新高** | 今天创了近 20 天新高，同时成交额过亿、收阳线、是真涨 |
| **均线金叉+放量突破** | 5 日均线刚上穿 20 日均线，同时成交量放大到均量的 1.5 倍 |
| **高位旗形缩量** | 先猛涨一波，然后缩量窄幅横盘、没掉下来（蓄势待发） |
| **涨停次日洗盘** | 昨天涨停，今天放量收阴但没跌破昨天收盘价（洗盘没破位） |
| **上升趋势跌停错杀** | 本来是多头趋势，今天突然放量跌停，博一个超跌反弹 |
| **RPS 极强动量** | 近 120 天涨幅排进全市场前 10%，且股价接近 120 天新高 |
| **定增公告监控** | 最近 7 天发了定向增发公告（事件驱动，不靠 K 线） |

7 套规则是**各自独立**的：同一只股票可能同时被好几套挑中，邮件里会分别列出来。

## 三、在自己电脑上跑一遍

### 第 1 步：装 Python

需要 **Python 3.11 或更新版本**。到 <https://www.python.org/downloads/> 下载安装即可。

> 为什么必须是 3.11+：配置文件用的是 Python 3.11 才有的内置模块。装完在命令行敲
> `python --version` 确认一下版本。

### 第 2 步：下载代码、装依赖

```bash
git clone https://github.com/hulk668/Sequoia-X-Auto.git
cd Sequoia-X-Auto

# 建一个独立的运行环境（推荐，避免污染电脑里的其他 Python）
python -m venv .venv
source .venv/bin/activate        # Windows 用户改成：.venv\Scripts\activate

# 装依赖
python -m pip install --upgrade pip
pip install akshare "pydantic-settings>=2.0" rich pandas requests
```

### 第 3 步：改配置文件（只改这一个文件）

```bash
cp config.example.toml config.local.toml
```

然后用记事本打开 `config.local.toml`，把邮箱那几行填上：

```toml
notify_channel = "email"

smtp_host = "smtp.qq.com"        # 用哪个邮箱发，见下面的对照表
smtp_port = 465
smtp_user = "你的邮箱@qq.com"     # 发件邮箱，要写完整地址
smtp_password = "你的授权码"      # ⚠️ 不是邮箱登录密码！
mail_to = "收件邮箱@example.com"  # 发给谁，多个用逗号隔开
```

**常用邮箱怎么填**：

| 用哪个邮箱发信 | smtp_host | 端口 | 授权码去哪拿 |
|---|---|---|---|
| QQ 邮箱 | `smtp.qq.com` | 465 | 设置 → 账号与安全 → 开启 SMTP 服务 → 生成授权码 |
| 163 邮箱 | `smtp.163.com` | 465 | 设置 → POP3/SMTP/IMAP → 开启 → 新增授权密码 |
| 阿里企业邮 | `smtp.qiye.aliyun.com` | 465 | 网页端设置 → 客户端设置 → 生成专用密码 |
| 钉钉企业邮 | `smtp.em.dingtalk.com` | 465 | 见下方说明 |
| Gmail | `smtp.gmail.com` | 587 | 先开两步验证，再申请「应用专用密码」 |

> 🔴 **最容易踩的坑**：`smtp_password` 要填的是**授权码**，不是你的邮箱登录密码。
> 授权码是邮箱后台单独生成的一串字符，专门给第三方程序用。

<details>
<summary><b>钉钉 / 阿里云企业邮箱怎么弄（点开看）</b></summary>

钉钉企业邮箱底层就是阿里云邮箱，服务器是同一台。有两个**必须都满足**的前置条件，
少一个都认证不成功：

1. **让管理员开开关**：钉钉管理后台 → 通讯录 → 邮箱管理 → 安全策略 → 第三方客户端管理。
   （官方说明里写了这个功能**默认是关的**，管理员不开就没有生成授权码的入口）
2. **你自己生成密码**：邮箱网页端 → 设置 → 账户与安全 → 账户安全 → 三方客户端登录安全管理 → 生成新密码。

注意：`xxx@dingtalk.com` 这种是钉钉送的**个人邮箱**，官方手册只讲了企业邮箱。
所以第 2 步能不能找到那一项，得自己登录网页端看一眼 —— 找不到就换个 QQ / 163 邮箱发信，
配置里改几个字就行，不用改代码。

</details>

### 第 4 步：准备数据

程序需要一个本地数据库（大概 300MB）。新下载的代码里没有，两种拿法：

**办法 A：下载现成的（推荐，几秒钟）**

打开 <https://github.com/hulk668/Sequoia-X-Auto/releases>，找到最新那个版本的
`sequoia_v2.db.gz`，下载后解压，把得到的 `sequoia_v2.db` 放到项目的 `data` 文件夹里。

> 文件名必须是 `sequoia_v2.db`。

**办法 B：自己下载（不依赖别人，慢一些）**

```bash
python main.py --backfill
```

这一步会去网上把全市场的历史 K 线拉下来，大概几分钟。中途 Ctrl+C 中断没关系，
下次重新跑会自动接着上次的进度。

### 第 5 步：跑起来

```bash
python main.py
```

跑完你就会收到一封邮件。日志里也能看到结果。

**如果只想看选股结果、不想重新下载数据**（调策略时常用）：

```bash
python main.py --skip-sync
```

几十秒就跑完，比完整跑一遍快得多。

### 附：先自检一下邮箱配置（强烈建议）

邮箱配置错了，一般要等到跑完几千只股票、发邮件那一刻才会发现。
所以先花 5 秒单独测一下：

```bash
python scripts/test_mail.py --preview   # 不联网也不发信，只看邮件长啥样（不需要密码）
python scripts/test_mail.py --no-send   # 测能不能连上、能不能登录，不发信
python scripts/test_mail.py             # 完整测一遍：连上 → 登录 → 给自己发一封测试邮件
```

它会直接告诉你问题出在哪，比如「你填的是登录密码，应该填授权码」。

## 四、让它每天自动跑（不用开电脑）

用 GitHub 的免费定时任务（GitHub Actions）。不用买服务器，也不用手动跑。

### 第 1 步：把代码复制到你自己的 GitHub 账号下

打开 <https://github.com/hulk668/Sequoia-X-Auto>，
点右上角的 **Fork** 按钮，复制一份到你自己账号下。

> 因为要天天跑、还要存数据库，用自己的仓库最方便。

### 第 2 步：配上邮箱信息

在你自己的仓库里，点 **Settings → Secrets and variables → Actions → New repository secret**，
把你邮箱的信息一条条加进去：

| Secret 名字 | 填什么 | 必填吗 |
|---|---|---|
| `SMTP_HOST` | 邮箱服务器地址，比如 `smtp.qq.com` | ✅ 必填 |
| `SMTP_USER` | 发件邮箱的完整地址 | ✅ 必填 |
| `SMTP_PASSWORD` | 邮箱的**授权码**（不是登录密码） | ✅ 必填 |
| `MAIL_TO` | 收件邮箱，多个用逗号隔开 | ✅ 必填 |
| `SMTP_PORT` | 不填默认 `465` | 可选 |
| `MAIL_FROM_NAME` | 邮件里显示的发件人名字，默认「SequoiaX-AutoPlus 选股」 | 可选 |
| `NOTIFY_CHANNEL` | 不填默认 `email`（发邮件）；填 `none` 就是不通知 | 可选 |

> ⚠️ **Secret 只填在这里，不要写进代码文件里**。代码文件是公开的，写了就等于把密码公开了。
> 万一不小心提交过，光删文件没用（历史里还在），必须去邮箱后台把授权码重置掉。

### 第 3 步：完事，等它自己跑

配置好之后，**每周一到周五北京时间 18:30** 会自动跑一次，结果发到你邮箱。

想立刻试一次：进仓库的 **Actions** 页面 → 左边选「SequoiaX-AutoPlus 每日选股」→
右边点 **Run workflow**。

> ⚠️ **改时间要注意**：GitHub 的定时任务用的是**世界标准时间（UTC）**，不是北京时间。
> 北京时间 18:30 = UTC 10:30，所以配置文件里写的是 `30 10 * * 1-5`。
> 想改成别的点，记得减 8 小时再填。

### 数据库在云端怎么保存？

数据库 300MB 左右，超过 GitHub 单文件 100MB 的上限，没法直接放进代码仓库，
所以用了「缓存 + 种子」两级方案：

1. **日常靠缓存**：每次跑之前先恢复上次的数据库，跑完再存一份新的。
2. **缓存丢了靠种子**：万一缓存被 GitHub 清理了（长时间没跑就会），
   自动从 Release 下载那份现成的数据库救急。

两级都没有，任务会**明确报错**，而不是假装成功却一只股票都没选出来。

### 几个要注意的地方

- **仓库 60 天不动会被暂停**：GitHub 的规矩，连续 60 天没有新提交就停掉定时任务。
  去 Actions 页面点一下重新启用就行。
- **定时会延迟**：用的人多的时候可能晚几分钟到几十分钟，也可能偶尔不触发。
  这是免费服务的正常现象，介意的话可以自己在服务器上跑。
- **第一次跑会慢一点**：要下载种子数据；之后都走缓存，就快了。

## 五、常见问题

**Q：邮件发不出去，提示认证失败？**
先跑 `python scripts/test_mail.py`，它会直接告诉你去哪改。九成是把**邮箱登录密码**填进了
`smtp_password` —— 那里要填的是**授权码**。

**Q：想把邮件发给自己以外的人？**
`mail_to` 填多个邮箱，用逗号隔开就行（中文逗号、英文逗号、分号都认）。

**Q：有时候邮件顶部带「⚠️ 数据截止 …」，正常吗？**
正常。意思是这次的名单是基于那一天的数据算的。如果截止日期离今天很远，手动跑一次
`python main.py` 补一下数据。

**Q：每天的名单都一样，是不是坏了？**
先看邮件顶部的日期。日期没变，就是数据没更新 —— 同一批数据必然算出同样的结果，
这是设计如此，不是 bug。

**Q：只想跑策略、不要邮件？**
把配置里的 `notify_channel` 改成 `"none"`，结果就只写在日志里。

**Q：会真的帮我买卖股票吗？**
不会。它只挑股票、只发名单，不碰你的账户。

**Q：数据从哪来？要花钱吗？**
行情来自 [akshare](https://akshare.akfamily.xyz)（背后是东方财富的公开接口）。
GitHub Actions 的定时任务免费。整个项目不花一分钱。

**Q：我的邮箱密码会不会泄露？**
不会，前提是别把它写进代码文件。本地跑的时候放 `config.local.toml`（这个文件被设置了
「不提交」），云端跑的时候放 GitHub Secrets。

## 六、项目里都有什么

```
SequoiaX-AutoPlus/
├── main.py                      程序入口（跑数据 + 选股 + 发邮件都从这开始）
├── config.example.toml          配置模板（复制成 config.local.toml 后填自己的值）
├── config.local.toml            ↑ 你填的配置，不会被提交到仓库
├── README.md                    本文件
├── RUNNING.md                   更详细的本地运行说明与排错
├── .github/workflows/
│   ├── daily.yml                每天定时选股
│   └── seed.yml                 手动打包数据库、发到 Release
├── scripts/
│   ├── test_mail.py             邮箱配置自检工具
│   └── pack_seed.py             把数据库打包成压缩包
├── data/                        数据库放这里（不进代码仓库）
│   └── seed/                    只存版本号，压缩包放 GitHub Release
├── sequoia_x/
│   ├── core/                    配置、日志
│   ├── data/                    数据库读写、抓行情、行业查询
│   ├── strategy/                7 个选股策略，一个文件一个策略
│   └── notify/                  渲染邮件、发邮件
└── tests/                       自动化测试
```

### 想自己加一个策略？

在 `sequoia_x/strategy/` 下照着现有的文件新建一个，
然后在 `main.py` 的策略列表里加一行、在 `sequoia_x/notify/strategies.py` 里登记一下中文名和买卖点，就行了。

### 数据存在哪、长什么样

- **数据库**：一个 SQLite 文件（`data/sequoia_v2.db`），拷贝到别的电脑也能直接用。
- **价格**：统一存**后复权**价（历史价格不会因为分红送股而变动，适合每天往上加数据）。
- **三张表**：`stock_daily`（每天的 K 线）、`stock_name`（股票名称）、`stock_board`（所属行业，缓存 30 天）。
- **行业**：取自东方财富的行业分类，邮件里那个「港口航运」就是它。
